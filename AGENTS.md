# Component file names

When creating components, name the file in PascalCase (e.g. `src/components/Select.tsx`), not kebab-case. Files in `src/components/ui/` are generated by shadcn and keep their lowercase names.

# UI copy

Don't add unnecessary subtitles, descriptions, or helper text. If a heading already says what something is (e.g. a "School profile" card), don't add a line restating it. Only add descriptive text when it tells the user something the heading and the content don't.
